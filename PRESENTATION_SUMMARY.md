## Architecture Overview (3 minutes)

### System Architecture
```
Frontend (React) → Backend (FastAPI) → Database (PostgreSQL)
                          ↓
                    Gemini AI API
```

### Key Components
- **Frontend**: React with TypeScript, Tailwind CSS
- **Backend**: FastAPI with async/await, SQLAlchemy ORM
- **Database**: PostgreSQL (with SQLite fallback)
- **AI**: Google Gemini Pro for natural language processing
- **Authentication**: JWT tokens with bcrypt password hashing

### Data Models
- **User**: Authentication and profile
- **Account**: Banking accounts (checking, savings, credit)
- **Transaction**: Financial transactions with categorization
- **ChatLog**: AI conversation history
